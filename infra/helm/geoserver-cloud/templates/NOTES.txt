Check the release with:
  helm status {{ .Release.Name }} -n {{ .Release.Namespace }}
  oc get pods,svc,pvc -l app.kubernetes.io/instance={{ .Release.Name }} -n {{ .Release.Namespace }}

The proxy Route is disabled by default. When enabled, it targets the OIDC proxy,
not the gateway. PVCs must not be deleted during an application rollback.
